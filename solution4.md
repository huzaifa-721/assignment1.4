, I learned the basics of Git version control. First, I installed Git on my computer and verified the installation using the git --version command. Then I opened the terminal in my project folder and converted it into a Git repository by running git init, which created a hidden .git folder. After that, I configured my Git username and email using git config. I created an HTML file and checked its status using git status. I staged the file using git add and made my first commit with a meaningful message using git commit -m. I repeated this process and made two more commits by adding a CSS file and a JavaScript file with proper commit messages. Finally, I checked the commit history using git log, which showed all three commits. This assignment helped me understand how Git tracks changes and maintains the history of a project.
